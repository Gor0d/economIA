Como chegamos a esta estimativa?

Multiplicamos seus tokens de entrada e saída pelos preços públicos de cada provedor. A comparação mantém o mesmo volume em todos os modelos; tokenizadores diferentes podem alterar o consumo real.

O modo Batch aplica o desconto oficial (~50%) só nos modelos cuja Batch API é documentada publicamente pelo provedor (OpenAI, Anthropic e Google); os demais mantêm o preço padrão nesse modo. Ainda não incluímos desconto de cache, de volume, nem tarifas especiais para contexto longo.

Onde otimizar primeiro

Como esta estimativa funciona e o que ela não inclui?

Estimativa: o texto é contado localmente por uma heurística calibrada por provedor. A contagem oficial pode divergir porque OpenAI, Anthropic e Google usam tokenizadores e overheads próprios. Nenhum texto digitado aqui é enviado para APIs externas.

Cache: a simulação trata a parcela informada como leitura de cache e o restante como input novo. Quando o provedor publica uma tarifa de gravação separada, ela é aplicada ao prefixo novo; armazenamento por hora não entra no total.

Consumo confirmado: futuramente poderá ser importado do objeto usage das APIs, incluindo input_tokens, cached_tokens, cache_write_tokens, output_tokens e reasoning_tokens. Hoje todos os números desta aba são pré-chamada.
