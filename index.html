Como chegamos a esta estimativa?

Multiplicamos seus tokens de entrada e saída pelos preços públicos de cada provedor. A comparação mantém o mesmo volume em todos os modelos; tokenizadores diferentes podem alterar o consumo real.

O modo Batch aplica o desconto oficial (~50%) só nos modelos cuja Batch API é documentada publicamente pelo provedor (OpenAI, Anthropic e Google); os demais mantêm o preço padrão nesse modo. Ainda não incluímos desconto de cache, de volume, nem tarifas especiais para contexto longo.
